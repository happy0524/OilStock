# 실행·검수 기록

2026-11-12, Windows PowerShell과 Python 3.10.11에서 실제 실행한 결과를 기록했습니다.

| 실행 | 결과 |
|---|---|
| `python scripts/verify_companies.py` | 한국 13개 코드·시장 대조 완료; 세기상사 현재 이름 차이 별도 표시 |
| `python scripts/run_analysis.py` | Yahoo 시세 5개 수집 묶음 완료, 사건 비교 34개 기업 모두 정확한 날짜의 종가 확보 |
| `python scripts/run_analysis.py --offline` | 원자료 캐시만으로 전체 재생성 완료, 종료 코드 0 |
| `python scripts/collect_candidates.py` | 실행 시점 미국 Energy 후보 21개·KOSPI 키워드 후보 25개; 고정 표본에 미반영 |
| `python -m pytest -q` | 13 passed; 수익률·기준일 결측·휴장·날짜 중복·비양수 가격·매출 매칭·원 수치 보존·캐시 무결성 확인 |
| `python scripts/execute_notebook.py` | 코드 셀 5개 순차 실행 완료, 오류 출력 없음 |
| `python scripts/check_artifacts.py` | 내부 링크 27개·실행된 노트북·그림 6개 검증 통과 |
| `python -m pip check` | 의존성 충돌 없음 |

실제 실행에서는 `python` 대신 프로젝트 `.venv\Scripts\python`을 사용했습니다. 사용한 주요 패키지 버전은 [실행 기록](../data/processed/run_manifest.json)에 남겼습니다.

분석용 CSV 14개와 실행 JSON 1개, 그래프 PNG 6개를 생성했습니다. README에는 대표 그림 4개를 연결하고 초기 미국 21개 패널 2개는 보고서 부록에 배치했습니다. 출력 그림을 모두 직접 열어 한글 표시·범례·축·라벨을 확인했고 세 시점 패널의 날짜 겹침을 줄이도록 회전과 여백을 조정했습니다.

제공 매출 104행의 원 수치·항목을 유지했습니다. 기간을 한 범위로 합치지 않았고 배타적 종료일, 첫 관측일 기준과 2/27 기준을 구별했습니다. 한국 휴장을 보간하지 않았으며 `auto_adjust`를 명시했습니다. TPL은 초기 표본에 유지하고 주 비교 제외 전후 요약을 남겼습니다. 파이를 국가 매출 비중으로 해석하지 않도록 회사별 원 비중 막대로 개선했습니다.

이전 실행 CSV·그림·라이브러리 버전이 없어 과거 결과와의 수치 차이는 직접 검증하지 못했습니다. 한국 주가 수집과 코드·시장 검증, 품질 검사, 캐시·해시, 테스트는 이번 재현에 추가했습니다. 테스트 결과를 경제적 가설의 통계 검증으로 해석하지 않았습니다.

현재 시가총액 추가 수집 옵션은 실행하지 않았습니다. 사건 당시 S&P 500 구성·시총·모든 중간 거래일을 별도로 인증하지 않았습니다. 매출 원문 URL·회계 기준·대부분 기준일, HD현대 캡처 원본, TPL 사후 제외 결정 시점의 상세 기록, 원 수업 프로젝트의 팀 구성과 개인 기여는 확인이 필요한 항목으로 남겼습니다. 공개 재배포 조건도 [출처 문서](../docs/sources.md)에 확인 범위를 기록했습니다.

Git 저장소 초기화·원격 생성·커밋·push·공개 배포는 실행하지 않았습니다. 사용자가 실행할 업로드 명령은 [재현 안내](../docs/reproduction.md)에 정리했습니다.
